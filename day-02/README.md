# Day 2 – Tip Calculator

## Overview

A command-line application that calculates how much each person should contribute toward a bill after adding a tip.

Although the project is simple, it has been engineered using professional development practices beyond the original course requirements.

## Features

- Input validation
- Positive number validation
- Bill splitter validation
- Logging
- Type hints
- Modular design
- Object-oriented implementation
- Colored terminal output
