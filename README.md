# 100 Days of Python Code – Engineering Edition

This repository documents my journey through Dr. Angela Yu's **100 Days of Python** course on Udemy.

Unlike a typical course repository, this project is being developed using professional software engineering practices. Every project is treated as though it were submitted in a real development team.

## Objectives

- Strengthen Python proficiency
- Practice writing clean, maintainable code
- Apply software engineering principles from Day 1
- Develop professional Git and GitHub workflows
- Learn testing, logging, documentation, and code review
- Build a portfolio that reflects industry standards

## Engineering Workflow

Every day follows the same process:

1. Complete the course project.
2. Commit the initial implementation.
3. Open a Pull Request.
4. Perform a professional code review.
5. Refactor the code based on review feedback.
6. Merge into the main branch.
